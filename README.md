# KuroChat Releases

KuroChat 桌面版（Windows）的安裝檔與 App 內更新來源；本 repo 不含原始碼。

## 安裝

到 [Releases](https://github.com/Stackssz-Lab/KuroChat-releases/releases/latest) 下載 `KuroChat_<版本>_x64-setup.exe` 執行即可；安裝檔未簽章，Windows SmartScreen 可能會警告。

## 更新

已安裝的 KuroChat 會在啟動時檢查新版，也可從系統匣選單的「檢查更新」手動檢查；每個安裝檔都附有簽章，App 驗證通過才會安裝。
